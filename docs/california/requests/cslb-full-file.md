## Why this is valuable

The free Public Data Portal omits cancelled, revoked, and expired-non-renewable licenses. The Full File is the official historical universe (830,000+ records, including expired 10+ years). It is not required to stand up the first California contractor state page.

## What to order (narrow)

- License Master **FULL** file only (January or July run).
- Do **not** order Business Principle, HIS, or custom sales extracts in the same request unless a later ticket needs personnel history.

## What we will not request

- Email addresses (CSLB does not provide them; BPC 27)
- DOB, SSN, residential address
- Personnel names in this order
- Programming/technical support from CSLB (form disclaimer)

## Semantic constraints

- Full File row ≠ currently licensed
- Cancelled/revoked/expired are historical statuses, not a ranking input
- Missing free-portal row ≠ missing Full File row
- Do not wait on this request to acquire the free master
