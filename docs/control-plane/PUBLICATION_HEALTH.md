# Publication Health

Source ingestion and publication are independent capability states. A current source may have degraded publication; a delayed source may still have a currently served accepted snapshot. Counts preserve their native grain and are never added into a synthetic network “company total.” Count anomalies are review signals only and never auto-unpublish.

Current specialist repositories expose heterogeneous checked-in snapshots/manifests and publication gates, but no common authenticated runtime publication-health adapter. Those capabilities begin UNKNOWN with `HEALTH_ADAPTER_NOT_INSTRUMENTED`. Ask stores only bounded health metadata and aggregate blast radius; specialists retain publication eligibility, indexability, normalization and Layer A truth.
