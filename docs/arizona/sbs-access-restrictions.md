# Arizona SBS report-generator access (ATH-AZ-001)

DIFI license search (`https://difi.az.gov/license-search`) instructs the public to buy a list from **NAIC State Based Systems**:

1. Select Arizona as the jurisdiction.
2. Select Generate a Report.
3. Search Type = Licensee.
4. Entity Type = Individual **or** Entity.

Official SBS support (`https://www.statebasedsystems.com/solar/support.html`, checked 2026-09-04):

- CSV
- **$0.03 per row**
- **$30.00 minimum** per report
- Preview of row count and cost before payment

This ticket did **not** purchase a report.

Access class: `OPEN_REPORT_GENERATOR_PAID`.

Paid ≠ acquired. SEARCH_ONLY lookup ≠ zero.

NPN is a person/producer identifier. NAIC is a company identifier. Producer ≠ agency ≠ company. Individual reports are people — do not publish people.

A later AZ-INS-001 may purchase an **Entity** report only if the owner authorizes spend. Until then Insurance remains SEARCH_PATH_ONLY.
