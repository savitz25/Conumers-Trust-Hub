- Scope: state-level only; no county or local routes.

## Evidence limits

Specialist page content is summarized without converting incomparable source observations into a combined census. Maine HMDA application activity and lender-license populations remain separate. Insurance counts refer only to an active nonresident producer workbook dated 2026-08-01. Senior, contractor, and securities-license record gaps remain `NOT_ACQUIRED`. Move’s official-source finding is that no mover-specific state roster was identified in the reviewed Maine framework; it is not a measured zero.

The state page links all six specialist routes, rejects combined totals, and does not publish ratings or a Trust Score. The gateway does not execute provider searches, add county routes, write Ask graph records, or expand claim eligibility.
