# Record issue review

Identify the exact challenged record and source of truth. Determine whether association is wrong, the source changed, ingestion is wrong, evidence is accurate but unfavorable, a source refresh is required, or more information is needed.

A submitted issue does not remove evidence. An active dispute does not mean evidence is false and creates no automatic public badge. Corrected outcomes create the existing ingest/reconciliation remediation task; staff must not edit official evidence directly. Keep correction analysis separate from business-response moderation and use neutral claimant notes.
