# Cache and publication latency

Ask successful public responses use `s-maxage=60, stale-while-revalidate=30`; missing or invalid projections are `no-store`. JSON endpoints are `noindex`. Contractor requests the account layer with `no-store` and a 1.5-second timeout.

For the controlled trial, the expected normal visible window is 60–90 seconds after save. Revocation, response withdrawal, and loss of qualifying membership use the same maximum expected edge window; correctness is prioritized over additional caching. Failures omit the business section while independent Trust Report evidence remains available.

Actual T0–T5 production latency must be recorded only against an owner-authorized canary. No such target may be inferred from ordinary customer data.
